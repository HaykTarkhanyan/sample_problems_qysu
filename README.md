# sample_problems_qysu

Armenian study material for Yerevan State University (ԵՊՀ) math courses, written with AI (Claude, earlier
also Gemini) and checked by scripts, independent math reviews and a browser pass. Live as a static site on
GitHub Pages, built from `site/`.

| course | folder | what is there |
|--------|--------|---------------|
| Numerical analysis | `site/numerical/`, `numerical_methods/` | solutions to the course problem list with theory, widgets, runnable Python and Manim videos; first page: splines and least squares (17 problems) |
| Probability theory | `site/probability/`, `probability/` | 15 lecture pages (weeks 1-8, 10-16) with interactive figures, exercises and reviews |
| Discrete mathematics | `site/discrete/`, `discrete/` | 7 practice sheets as LaTeX/PDF (English and Armenian) and as site pages |
| Group theory | `group_theory/` | practice 10, kept for reference, not maintained |

Other folders: `armenian_style/` (Armenian style guide and lint), `animations/` (Manim scenes), `tools/`
(site QA and search index builder), `glossary_Apr.csv` (master English-Armenian term list).

How things are built and checked: `CLAUDE.md`, `CONVENTIONS.md`, and the reasons behind each choice in
`DECISIONS.md`.
