### 4. `w-word`: letters outside the stated rule
- **Severity:** MINOR / note. From reading the code, to be tested in the browser.
- «և» is one letter; «եւ» is two (ե, ւ); «ԵՎ» is two (ե, վ). Consistent with the rule the widget states.
- A word with a stand-alone «ւ» and a stand-alone «ո» (classical spelling or junk input) can give the same string
  from two different arrangements of the units, so the count would be too high there. Not reachable with a modern
  Armenian word.
- An emoji is two UTF-16 halves for `splitLetters`; the error message would print two broken characters.
