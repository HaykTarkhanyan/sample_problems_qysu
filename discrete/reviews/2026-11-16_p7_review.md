**Does it fire?** Yes. (1) With the answer of self-check 5 squeezed into a 150 px box, as in the builder's

(2) On the unchanged page at widths the site does not promise: 3 hits at 320 px, 11 at 280 px.

**The builder's probe** (`logs/p7_shots.mjs`, step `overflow`) fires in the same two tests, so it works, but it
measures only the `.katex` box: the suffix that `site.js` glues to the formula is not counted. It therefore
reports less (38 px where the glued unit is 53 px over) and misses the 360 px case, where only the glued «-ը»
sticks out. Mine measures the `.glue` span when there is one, subtracts the border as well as the padding, treats
`inline-block` and `inline-flex` boxes (buttons, chips) as containers, and marks hits inside a sideways scroller.

Code (runs in the page after everything is opened; in `browser_check.mjs` it would sit next to `measure()`):

```js
function inlineOverflow() {
  const tex = el => {
    const a = el.querySelector("annotation");
    return (a ? a.textContent : el.textContent).replace(/\s+/g, " ").trim().slice(0, 70);
  };
  const out = [];
  document.querySelectorAll(".glue, .katex").forEach(el => {
    if (el.closest(".katex-display")) return;                              // display formulas have their own check
    if (el.classList.contains("katex") && el.closest(".glue")) return;     // measured once, through its glue span
    const r = el.getBoundingClientRect();
    if (r.width === 0 || r.height === 0) return;                           // hidden (closed section, try mode)
    // nearest ancestor that makes its own box: anything that is not display:inline / contents
    let blk = el.parentElement;
    while (blk && /^(inline|contents)$/.test(getComputedStyle(blk).display)) blk = blk.parentElement;
    if (!blk) return;
    const cs = getComputedStyle(blk), b = blk.getBoundingClientRect();
    const edge = b.right - (parseFloat(cs.paddingRight) || 0) - (parseFloat(cs.borderRightWidth) || 0);
    const over = r.right - edge;
    if (over <= 1) return;
    // a box that scrolls sideways on purpose (table-wrap) is not a clipped formula
    let sc = blk, scrolls = false;
    while (sc && sc !== document.body) {
      if (/(auto|scroll)/.test(getComputedStyle(sc).overflowX) && sc.scrollWidth > sc.clientWidth + 1) { scrolls = true; break; }
      sc = sc.parentElement;
    }
    const sec = el.closest("details.sec, section[id]");
    out.push(`${Math.round(over)} px past the edge of <${blk.tagName.toLowerCase()}` +
      `${blk.className ? "." + String(blk.className).trim().split(/\s+/).join(".") : ""}>` +
      `${scrolls ? " (inside a sideways scroller)" : ""}${sec && sec.id ? " in #" + sec.id : ""}: ${tex(el)}`);
  });
  return out;
}
```

It was run on this page only. Before it becomes a failure in the gate it should be run on all pages once.
