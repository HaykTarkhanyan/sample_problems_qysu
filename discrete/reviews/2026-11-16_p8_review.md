## Findings so far (all provisional, none fixed)

### 1. `w-seq`, q = 0 and p = 0: «$a_n=a_2\cdot 0^{\,n-2}$» for n >= 2
- **Severity:** candidate WRONG or UNCLEAR. From reading the code (`cdMessage`, branch "first"). Not confirmed in
  the browser, not fixed.
- **What the widget prints:** «... կանոնն առաջին կարգի է՝ $a_n=0a_{n-1}$։ Ուրեմն $n\ge2$-ի համար
  $a_n=a_2\cdot 0^{\,n-2}$ ...».
- **What is right:** for n = 2 this reads `a_2 = a_2 * 0^0`, which holds only with the convention 0^0 = 1. The plain
  statement is: a_n = 0 for every n >= 3. For p != 0 the message `a_n = a_2 * p^{n-2}` (n >= 2) is right.
- **Planned:** confirm in the browser, then give p = 0 its own sentence.

### 2. `w-seq`, irrational roots: a constant can be printed as 0
- **Severity:** candidate WRONG in some state, to be searched by script. From reading `decTex` (3 decimals).
- A constant C or D smaller than 0,0005 in absolute value would be printed «$C\approx0$» and the closed form as
  `... + 0 * (...)^n` although it is not zero. I do not know yet whether any slider state reaches this.

### 3. `w-seq`, irrational roots: «$r_{1,2}=\frac{p\pm\sqrt{\dots}}{2}$, այսինքն՝ $r_1\approx$ (smaller), $r_2\approx$ (larger)»
- **Severity:** MINOR. With `±` a reader takes r_1 as the `+` root; the widget gives r_1 the `-` root.

### 4. `w-seq`, complex roots with p = 0: «$\frac{0\pm i\sqrt{4}}{2}$»
- **Severity:** MINOR (true, not simplified). From reading the code.

### 5. `w-seq`, ratio line: «≈ -0,00» possible
- **Severity:** MINOR, unverified. `toFixed(2)` of a small negative ratio.

### 6. New check box: «նույնիսկ սխալ արմատներով բանաձևը կհամընկներ նրանց հետ»
- **Severity:** candidate MINOR. True when the wrong roots are different and non-zero (then the 2x2 system has a
  solution); the page's own sign-error example satisfies this. To be weighed after the scripts.

### 7. Key idea 1 and the summary: "two different roots -> $Cr_1^n+Dr_2^n$"
