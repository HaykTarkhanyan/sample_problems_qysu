## Findings

### 1. `w-seq`, irrational roots: a non-zero constant printed as 0
- **Severity:** WRONG (a false formula on screen in 12 of the 81 220 slider states with irrational roots). **Fixed.**
- **What the widget showed:** p = -6, q = 8, a_1 = 8, a_2 = 9: «... $r_1\approx-7{,}123$, $r_2\approx1{,}123$։
  Նույն եղանակով՝ $C\approx0$, $D\approx7{,}125$» and in the legend «$a_n\approx0\cdot(-7{,}123)^n+7{,}125\cdot
  (1{,}123)^n$». The same widget's table gave a_10 = 86 784 and its last line said that the component of -7,123
  dominates.
- **What is right:** C = 0,000258, not 0. The printed formula gives 22,7 at n = 10, the sequence is 86 784:
  `C r_1^10` is almost all of it. The other 11 states: (p, q, a_1, a_2) = (-6, 6, 8, 7), (-6, 9, 4, 5),
  (-6, 9, -4, -5), (-5, 4, 10, 7), (-5, 7, 7, 8), (5, 4, 10, -7), (5, 7, 7, -8), (6, 6, 8, -7), (6, 8, 8, -9),
  (6, 9, -4, 5), (6, 9, 4, -5). In all 12 the constant printed as 0 is between 0,00026 and 0,00048 in absolute value
  and belongs to the dominant root. Seen in the browser for (-6, 8, 8, 9), (5, 4, 10, -7) and (-6, 9, 4, 5); the
  list comes from my scan over all states.
- **Fix:** `decTex` in `p8.js` keeps 2 significant digits for a non-zero value below 0,01, 3 decimals otherwise.
  The state now reads «$C\approx0{,}00026$» and «$a_n\approx0{,}00026\cdot(-7{,}123)^n+7{,}125\cdot(1{,}123)^n$».
  `p8_widgets_check.mjs` now asserts this state and that no closed form of any irrational state has a 0 coefficient
  (12 with the builder's script, 0 now).

### 2. `w-seq`, legend and widget hint: "the larger root's component"
- **Severity:** WRONG (a label that is false in 79 of the 247 positions of p and q). **Fixed.**
- **What the widget showed:** the blue line was always labelled «(մեծ արմատի բաղադրիչը)», and the hint on the page
  said «Գրաֆիկում կապույտը մեծ արմատի բաղադրիչն է». With p = -6, q = 9 the roots are -7,243 and 1,243 and blue is
  «$-0{,}062\cdot(-7{,}243)^n$»: the component of the smaller root. With a double root (preset «կրկնակի արմատ»)
  blue is «$n\cdot2^n$» and there is no larger root.
- **What is right:** blue is the component of the root that is larger in absolute value (the widget's own last line
  says «բացարձակ արժեքով մեծ արմատին»); in 73 of the 155 pairs (p, q) with two different real roots that is the
  smaller root. For a double root blue is the part with the factor n.
- **Fix:** the legend says «(բացարձակ արժեքով մեծ արմատի բաղադրիչը)» when blue belongs to r_1, «($n$ արտադրիչով
  բաղադրիչը)» for a double root, and keeps «(մեծ արմատի բաղադրիչը)» otherwise. The hint: «կապույտը բացարձակ արժեքով
  մեծ արմատի բաղադրիչն է (կրկնակի արմատի դեպքում՝ $n$ արտադրիչով բաղադրիչը)». Question R5.

### 3. `w-seq`, p = 0 and q = 0: «$a_n=a_2\cdot 0^{\,n-2}$» for n >= 2
- **Severity:** UNCLEAR. **Fixed.**
- **What the widget showed:** «$q=0$, այսինքն՝ $a_{n-2}$-ը բացակայում է, և կանոնն առաջին կարգի է՝ $a_n=0a_{n-1}$։
  Ուրեմն $n\ge2$-ի համար $a_n=a_2\cdot 0^{\,n-2}$ ...».
- **What is right:** at n = 2 this reads a_2 = a_2 * 0^0, true only with the convention 0^0 = 1. The plain fact:
  a_n = 0 for every n >= 3. For p != 0 the message `a_n = a_2 p^{n-2}` (n >= 2) is right, and so is the remark that
  a_1 has no effect; the term a_0 does not appear anywhere in the widget.
- **Fix:** p = 0 has its own sentence: «$p=0$ և $q=0$, այսինքն՝ կանոնը $a_n=0$ է ($n\ge3$), իսկ $a_1$-ը և $a_2$-ը
  հաջորդ անդամների վրա չեն ազդում։»

### 4. `w-seq`, complex roots: "the method box covers only real roots"
- **Severity:** UNCLEAR. **Fixed.**
- **What the widget showed:** «Այս էջի մեթոդի վանդակը միայն իրական արմատներն է դիտարկում, այնպես որ աղյուսակի
  անդամները հաշվված են միայն ռեկուրենտ առնչությամբ։»
- **What is right:** the method box says «Երկու տարբեր արմատ $r_1\neq r_2$՝ ընդհանուր լուծում $a_n=Cr_1^n+Dr_2^n$»

- **Fix:** «Այս էջում միայն իրական արմատներն ենք դիտարկում, այնպես որ ...». It says what the page does and nothing
  about the formula. Question R4; the builder's Q5 is about the same place.

### 5. Summary table: «հաշվել արգելված բլոկ չպարունակող տողերը» -> `f(n) = f(n-1) + f(n-2)`
- **Severity:** UNCLEAR. **Fixed.**
- **What the page said:** the row is about any forbidden block, the method cell gives «ըստ վերջին նշանի՝
  $f(n)=f(n-1)+f(n-2)$».
- **What is right:** that recurrence belongs to the block «00» (and «11»). Strings without «01»: 2, 3, 4, 5, 6, ...
  (n + 1); without «000»: 2, 4, 7, 13, 24, ...
- **Fix:** «ըստ վերջին նշանի. «$00$» բլոկի համար՝ $f(n)=f(n-1)$ $+\,f(n-2)$, իսկ բազային դեպքերը՝ ձեռքով». Question R6.

### 6. Key idea 1: `C r_1^n + D r_2^n` without q != 0
- **Severity:** UNCLEAR. **Fixed.**
- **What the page said:** «$a_n=p\,a_{n-1}+q\,a_{n-2}$ առնչության մեջ տեղադրում ենք ... Երկու տարբեր արմատի դեպքում
  ընդհանուր լուծումը $C r_1^n+D r_2^n$ է».
- **What is right:** with q = 0 the roots are 0 and p, and the form cannot fit a general pair: a_n = 2a_{n-1}
  (n >= 3), a_1 = 1, a_2 = 5 gives 1, 5, 10, 20, ..., which is not `D * 2^n`. The old Step 3 says "neither root is
  0" and the old method box says "second order"; the new box said neither, and the new widget lets the reader set
  q = 0.
- **Fix:** «$a_n=p\,a_{n-1}+q\,a_{n-2}$ ($q\ne0$) առնչության մեջ ...». The summary table and the remember list repeat
  the form without the condition; I left them, they point back to Problem 2.
