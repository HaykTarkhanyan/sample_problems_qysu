## Findings so far

### 1. Predict block before `w-grid` (problem 1.5): "the answer is in the last line" points at the wrong line
- **Severity:** WRONG. **Not fixed yet.**
- **What the page says:** the why-text of the question "how many of 1..699 are divisible by 3 or 5" ends with
  «Ստուգեք ներքևի ցանցում՝ երբ երկու կոճակն էլ միացված են, պատասխանը վերջին տողում է։».
- **What is right:** in the state the question is about, which is also the widget's start state (N = 699, a = 5,
  b = 3, both toggles on), the last line of the widget is «Սա խնդիր 1.5-ն է՝ պատասխաններն են $139$, $46$ և $46$։».
  The answer 326 is in the line before it («Կցման-արտաքսման սկզբունքով՝ ... $139+233-46=326$ են։»). Read from the
  browser in `b2_grid.mjs` ("LAST line of the default state"). In every other state the 326-type line is the last
  one, so the sentence is false exactly where the reader is sent.
- **Fix planned:** in `gridLines` (`p5.js`) put the «Սա խնդիր 1.5-ն է ...» line before the inclusion-exclusion line,
  so that the latter is last in every state; no Armenian text changes. The builder's widget check has to follow if
  it asserts the order (not looked at yet).

### 2. `w-grid`: the drawing's `aria-label` keeps the old divisors
- **Severity:** WRONG by the rule "a message that is false in a reachable state" (hidden text, read by screen
  readers only). **Not fixed yet.**

  the browser: with a = 2, b = 4 it reads «... 12-ական թվով տողերում, 4-ի և 3-ի բազմապատիկները գունավորված», with
  a = 3, b = 3 it reads «... 3-ի և 4-ի ...».

- **Fix planned:** set the label in `render()`.

- **Key ideas:** ⌊N/d⌋ counts the multiples of d in 1..N (all N ≤ 300, d ≤ 40); "divisible by a and b" is
  "divisible by lcm(a, b)" (a, b ≤ 60); the bound ⌈k/n⌉ holds and is attained (all n ≤ 4, k ≤ 7).
