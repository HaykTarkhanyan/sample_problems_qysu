# armenian_style moved

The Armenian style guide, the owner's decisions, the house rules, the source findings and the lint now live in the `armenian-style-guide` skill, published at https://github.com/HaykTarkhanyan/armenian-style-guide (installed locally as `~/.claude/skills/armenian-style-guide/`).

Run the lint with `python -I ~/.claude/skills/armenian-style-guide/scripts/lint_armenian.py --style FILE...`.

The last version kept in this repo is at commit `af7b31d`. The gitignored `_sources/` folder stays here: the downloaded references and analysis scripts behind the guide.
