Խնդիրների լուծումներ՝ նկարներով և Python կոդով

Ամեն էջ սկսվում է կարճ տեսությունից, որին հաջորդում են խնդիրների ցանկի մի բաժնի բոլոր խնդիրների լուծումները։ Լուծումները սկզբում թաքցված են՝ նախ փորձեք ինքներդ։ Ինտերակտիվ նկարներում կարելի է քաշել կետեր և փոխել պարամետրերը, իսկ Python կոդը կարելի է գործարկել հենց էջում։
